## LLM 앱
- 모델에 보낼 필요가 없는 개인정보·비밀값(로그·외부 문서 속)은 보내기 전에 가린다. {{judge}}
- 도구 사용 루프에는 최대 횟수와 토큰·비용 한도를 둔다. {{judge}}
- 모델 출력(JSON·도구 인자)은 검증한 뒤에 파일·DB·외부 호출에 쓴다. {{judge}}
- 모델 이름은 코드에 박지 않고 설정에서 읽는다. {{judge}}
- 시험은 가짜 클라이언트로 돌리고, 실제 API 호출은 사용자에게 묻고 한다. {{judge}}
- 도구 결과·검색한 문서는 지시가 아니라 데이터로 다룬다(프롬프트 주입). {{judge}}
- 프롬프트·검색 방식을 바꾸면 평가 셋이 있으면 돌려 전과 견주고, 없으면 몇 개 만들자고 제안한다. {{judge}}
