## Collaboration
- Commits use `type: description` (e.g. `feat: add login`); a hook blocks other formats. {{hook:commit-msg}}
- Write commit messages that explain what changed and why. {{!hook:commit-msg}}
- One reason per commit — never mix refactoring with features.
- PR descriptions say what, why, and how it was verified.
- Never rewrite pushed commits (no rebase/amend); fix with a new commit.
