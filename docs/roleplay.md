# 역할극 기록 — harness-fit 을 고친 근거

> 최종 수정: 2026-11-13 · 분야가 다른 가짜 프로젝트에서 진짜 세션에 harness-fit 을 쓰게 하고, 의도대로 동작했는지·추천이 맞았는지를 정답지로 판정해 고칠 점을 찾는다

`<역할극 폴더>` = 내 컴퓨터의 `Downloads\find-your-skill-역할극\` (저장소 밖). 분야마다 `<번호-분야>\` 아래 시험 저장소와 `역할극\`(메모·답 기록·판정)을 둔다. 정답지는 `_정답지\`, 의뢰인·판정 규칙은 `_진행\`.

## 하는 법
1. 시작 코드: 그 분야 사람이 처음 며칠 만든 만큼의 저장소를 만든다(팀이면 커밋 작성자를 나눈다). 커밋까지 하고 깨끗한 상태를 기준점으로 둔다.
2. 메모(의뢰인이 아는 사실·걱정·싫은 것)와 정답지(분야 전문가가 기대하는 것: M 꼭, G 좋음, X 안 됨)를 먼저 쓴다. 정답지는 의뢰인·시험 세션에 보이지 않는다.
3. 시험 세션: 플러그인은 그 회차의 커밋을 떼어 둔 사본으로 단다(`git archive <커밋> | tar -x -C <역할극 폴더>\_plugin\<커밋>` — 도는 동안 메인 세션이 코드를 고쳐도 세션이 바뀌지 않게, 판정도 같은 사본으로). 사이드바에 올리지 않고 메인 세션 탭 옆 창으로: `orca terminal split --terminal <메인 창> --direction horizontal --command "cd '<시험 저장소>'; claude --dangerously-skip-permissions --plugin-dir '<사본>'"`. 첫 화면 「trust this folder」는 아래 화살표 + Enter. 2026-11-13 에는 이 한 줄 명령으로 연 세션이 모두 메인 저장소 폴더에서 떴다(bash 에서 경로를 변수로 이어 붙인 글이 깨졌다). 빈 창을 split 으로 열고, `PS` 프롬프트가 보인 뒤 `cd "<시험 저장소>"` 를 경로 그대로 보내고, 프롬프트의 폴더를 확인한 뒤 `claude …` 를 따로 보낸다. 세션 머리줄의 폴더가 시험 저장소인지 꼭 본다.
4. 의뢰인은 메인 세션의 백그라운드 하위 에이전트(메모만 앎, `_진행\의뢰인-규칙.md`). 세션에 `/harness-fit:setup auto` 를 보내고, 적용 전에 「넣을 것마다 왜 넣는지 md 문서로」를 한 번 부탁한 뒤 메모의 걱정·싫은 것만 사용자 말로 말하고 「그대로 적용」. 화면(브라우저) 대신 말과 문서로 한다. 세션의 일은 스킬·훅·지침뿐이고, 개발 환경·앱 코드는 사용자 역이 거절한다.
5. 점검: `node scripts/dev/roleplay-audit.mjs <시험 저장소>` — SKILL.md auto 절차를 빠짐없이·순서대로 했는지, 하면 안 되는 일, 적용 보고가 경고를 다 말했는지. 기대하는 일은 그 파일의 STEPS 한 곳에만.
6. 판정: 새 판정 에이전트(`_진행\판정-규칙.md`)가 두 가지만 본다 — ① 의도대로 동작했나(절차·감지·적용 결과·경고와 보고가 사실과 맞나, 「보고 틀림」) ② 추천이 맞았나(정답지 항목마다 harness-fit 이 넣은 것이 다룸/글로만/없음, 관련 없는 것, 카탈로그에 있는데 못 넣은 것). 세션이 harness-fit 밖에서 스스로 만든 훅·코드는 성과로 세지 않는다. 훅은 샘플 입력으로 실제로 막는지 잰다.
7. **통과 기준**: 점검 0, 보고 틀림 0, 관련 없음 0, 카탈로그에 있는데 못 넣은 M 항목 0, 카탈로그에도 없는 M 항목 1개 이하. 통과하면 다른 분야로, 못 넘으면 harness-fit(감지·카탈로그·조합·훅·SKILL.md)을 고쳐 같은 분야를 기준점에서 다시. 4번 연속 통과하면 끝. 판정 전에 메인 세션이 파일을 직접 열어 본다.

사용자 결정(2026-11-11): 동시에 도는 것은 프로젝트 3개까지, 프로젝트마다 세션 하나. 플러그인 없는 비교 세션(오답지)은 두지 않는다 — 보는 것은 플러그인이 의도대로 동작했나·추천이 맞았나 두 가지뿐이다. 처음에 세션 10개(시험 5·비교 5)를 한꺼번에 돌렸더니 시험이 시간 초과로 떨어지고, 비교 세션이 「설정해 줘」를 개발 환경까지로 읽어 도커 이미지를 빌드해 컴퓨터가 무거워졌다.
