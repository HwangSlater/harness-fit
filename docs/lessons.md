## JS 파일을 셸 스크립트로 고치지 않는다
- 증상: python·node 인라인 스크립트(heredoc 안 문자열 치환)로 .mjs 를 고치다 `\b`·`\n`·`\s` 가 백스페이스·줄바꿈으로 바뀌어 정규식이 깨졌다. 이번 세션에서만 4번(git.mjs, shell.mjs, tokens.mjs, apply.mjs).
- 할 것: 코드 수정은 Edit/Write 도구로. 여러 곳을 한꺼번에 바꿔야 하면 파일 전체를 Write 로 다시 쓴다. JSON 데이터만 node 로 고친다(문자열 이스케이프가 없는 것).

## 화면 문구는 실제 동작과 같은 데이터에서 만든다
- 증상: 「브랜치 방식을 고르면 관련 검사도 같이 맞춰져요」라고 써 놓고 실제로는 훅이 안 바뀌었다. CLAUDE.md 에는 꺼 둔 훅을 「훅이 검사」라고 적었다. 사용자 역할 평가에서 두 사람 모두 짚었다.
- 할 것: 설명 문구를 쓸 때 그 약속을 지키는 코드가 같은 데이터(packs.json 등)를 보고 있는지 확인한다. 사용자 역할 에이전트 평가를 화면을 바꿀 때마다 돌린다.
